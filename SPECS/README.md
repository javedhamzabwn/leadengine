# LeadEngine Feature Specs

Create one focused spec per major feature.

Recommended format:
- Goal
- User stories
- Inputs
- Outputs
- Data model
- API
- UI
- Error states
- Security
- Tests
- Acceptance criteria
- Open questions

Examples:
- people-search.md
- company-search.md
- enrichment.md
- exports.md
- saved-searches.md
- billing.md
- crm-integrations.md
