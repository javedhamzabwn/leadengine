# LeadEngine Monetization

## Credit Types
- Search credits
- Email reveal credits
- Phone reveal credits
- Export credits
- API credits
- Enrichment credits

## Example Plans

### Free
- limited searches
- masked contact fields
- limited exports

### Starter
- more searches
- email reveals
- basic exports
- saved searches

### Growth
- higher limits
- phone reveals
- enrichment
- lists
- integrations

### Pro
- API
- webhooks
- larger exports
- advanced enrichment
- team features

### Enterprise
- SSO
- SCIM
- audit logs
- custom limits
- SLA
- dedicated infrastructure

Exact pricing should be validated separately.

## Usage Tracking
Record:
- user
- organization
- action
- resource
- credits charged
- timestamp
- request_id

Never charge credits before authorization and successful action state is known.
